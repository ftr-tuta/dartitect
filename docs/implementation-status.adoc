== Hosted-only invariant

No gate requires a phone, tablet, iPhone, USB connection, private ADB socket, or
privately managed runner. Android runtime uses a clean API 34 Google APIs AVD on
`ubuntu-24.04`; iOS runtime uses an installed simulator on `macos-15`. A boot or
simulator availability failure makes `CI / Required` fail.

== Permanent architecture invariants

* constructor injection and explicit owned/borrowed lifetime;
* local persistence remains presentation authority;
* consumer-owned retry, auth, schema, transaction, and conflict policy;
* dependency-free core and isolated optional capabilities;
* fresh graph construction and reverse teardown in every isolate.

Stable `1.1.0` promotion used machine-readable `ui-quality-v2` and
Actions-readiness evidence. Future documentation and skill corrections stay
under the uniform `Unreleased` changelog section. They do not authorize a
`1.1.1` release, tag, or publication workflow.
