== Permanent invariants

* constructor injection and explicit owned/borrowed lifetime;
* local persistence remains presentation authority;
* retry, auth, schema, transactions, compensation, and conflict policy remain
  consumer-owned;
* core stays dependency-free and optional capabilities stay isolated;
* every isolate builds and tears down a fresh graph;
* Git consumption, formal readiness, signed distribution, stable readiness,
  and publication remain distinct decisions.
