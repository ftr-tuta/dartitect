= Public API review for the 1.0 release candidate

Review date:: 2026-08-25
Reviewed version:: lockstep `1.0.0-rc.1` cohort
Snapshot gate:: `dart run tool/check_api_snapshot.dart`

== Result

The checked API snapshot covers all 17 public entrypoints and matches their
source declarations. New ecosystem entrypoints are deliberately narrow;
existing entrypoints remain source-compatible with the reviewed development
cohort.

[cols="2,3",options="header"]
|===
| Entrypoint | Review result

| `package:dartitect/dartitect.dart`
| Stable core ownership, Result, command lanes, equality, and projection
contracts; no Flutter or provider dependency.

== Editorial and compatibility checks

All publishable packages retain English and Portuguese READMEs, changelogs,
licenses, examples, repository metadata, and lockstep versions checked by
`tool/check_public_docs.dart`. API declarations, generated MCP catalog, and
documentation examples are checked in the release audit. The compatibility
entrypoint remains thin; advanced reactive APIs require a deliberate import and
Material remains consumer-owned. No experimental API is presented as stable.

== Decision

The API surface is suitable for the current release-candidate line and a
controlled pre-release use. Final RC approval remains governed by the separate
readiness record and requires CI and Security evidence for the final candidate
SHA.
