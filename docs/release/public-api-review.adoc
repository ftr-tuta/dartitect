= Public API review for Dartitect 1.0.0

Review date:: 2026-08-31
Reviewed version:: `1.0.0`, promoted from the RC10 API baseline without additions or removals
Snapshot gate:: `dart run tool/check_api_snapshot.dart`
Document status:: Historical evidence for the released `v1.0.0` API

== Result

The checked API snapshot covers all 32 public entrypoints and matches their
source declarations. New ecosystem entrypoints are deliberately narrow;
pre-1.0 aliases and architecture overlap controls are intentionally absent.

== Editorial and compatibility checks

All publishable packages retain English READMEs, changelogs,
licenses, examples, repository metadata, and authority-declared compatible
versions checked by
`tool/check_public_docs.dart`. API declarations, generated MCP catalog, and
documentation examples are checked in the release audit. The compatibility
entrypoint remains thin; advanced reactive APIs require a deliberate import and
Material remains consumer-owned. No public Dartitect API retains an
experimental marker.

The final pre-release diff made config-v3 semantic factories and concrete application,
session, feature runtime/host, and harness outputs the paved road. It adds
typed OpenAPI operation selection, schema-2 consumer tax, fleet
inventory/impact, confined blueprints, 12-scenario change tax, and a mandatory
canary catalog for all packages, entrypoints, renderers, profiles,
capabilities, providers, scopes, and targets. No general application conversion
or debt-baseline path exists. Presentation helpers remain mechanical and
consumer-owned; `ui-quality-v1` now provides the stable-promotion evidence.

The semantic snapshot schema records constructors, members, parameters,
generic bounds, defaults, modifiers, annotations, and return types. Every
symbol is assigned to application-facing, extension-author, generated-code,
adapter-author, or tooling/test audience; diffs are classified as additive,
deprecated, or breaking and checked against the declared version.

== Decision

The API surface was accepted for stable `1.0.0`. The required
`CI / Required` result and unaltered `actions-readiness-v1` artifact were
completed before annotated tag `v1.0.0` and the immutable GitHub Release were
created.
