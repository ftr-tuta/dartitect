= Public API review for the 1.0 release candidate

Review date:: 2026-08-28
Reviewed version:: lockstep `1.0.0-rc.5` candidate cohort
Snapshot gate:: `dart run tool/check_api_snapshot.dart`

== Result

The checked API snapshot covers all 24 public entrypoints and matches their
source declarations. New ecosystem entrypoints are deliberately narrow;
existing entrypoints remain source-compatible with the reviewed development
cohort.

== Editorial and compatibility checks

All publishable packages retain English READMEs, changelogs,
licenses, examples, repository metadata, and lockstep versions checked by
`tool/check_public_docs.dart`. API declarations, generated MCP catalog, and
documentation examples are checked in the release audit. The compatibility
entrypoint remains thin; advanced reactive APIs require a deliberate import and
Material remains consumer-owned. No experimental API is presented as stable.

The RC5 diff intentionally activates the five reviewed deferrals and completes
the paved road before 1.0: typed command progress, bounded local history,
explicit lazy computed values, versioned UI restoration, read-only DevTools,
resilience, jobs, transfer, application/session hosts, feature profiles,
contract matrices, diagnostics protocol v2, and the isolated fleet canary
runner. Existing command constructors and blueprint names remain compatible.
No stable deprecation is removed. These changes require a fresh prerelease
candidate and complete same-SHA canaries rather than a patch claim.

== Decision

The API surface is suitable for the current release-candidate line and a
controlled pre-release use. Final RC readiness requires `CI / Required` and the
unaltered `actions-readiness-v1` artifact for the final candidate SHA.
