== Android AVD lifecycle

The workflow provisions the image directly with the Android SDK, recreates a
clean AVD, disables animations, and bounds boot with a timeout. A hosted
infrastructure boot failure receives one complete AVD recreation; test failures
are not masked by fallback. Diagnostics upload only on failure and contain
emulator metadata and logcat. The runner always attempts cleanup and shutdown.

== Manifest identity

Every cell manifest records exact versions, source SHA and tree, GitHub run ID
and attempt, workflow URL, hosted runner identity, ordered UTC interval, exact
scenario set, and clean-tree result. Hardware identifiers, installed-app
retention, manual receipts, and artifacts from another execution have no schema
slot.

The aggregate job downloads all five manifests from its own run and validates
their exact set. Missing, duplicate, failed, cancelled, skipped, cross-run,
cross-SHA, cross-tree, or malformed manifests fail `CI / Required`. The main
readiness artifact hashes each manifest so later alteration is detectable.

No phone, tablet, iPhone, USB connection, or private runner is required. Local
execution is optional feedback and never formal evidence.
