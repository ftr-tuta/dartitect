== Executable quality scope

`ui-quality-v2` binds seven practices to evidence: constraint-driven
responsiveness, DevTools runtime inspection, reusable widgets and previews,
MVVM, provider-neutral repositories, multiplatform behavior, and tests. The
contract requires Native Strict boundaries; semantic `DT3120`-`DT3145`
analysis with syntax-only warning parity; disposable preview discovery;
Memory, Drift, and ObjectBox repository behavior; responsive canary journeys;
and structural performance invariants without timing or memory thresholds.

The deterministic hosted graph coordinates Linux, Windows, macOS, Android
emulator, Drift Web, clean-clone audit, Git consumption, and OSV. Linux runs
both the Flutter 3.47.1 floor and current stable cells, producing nine
executions for the eight job identifiers consumed by `CI / Required`.

== Required evidence

Local and deterministic CI evidence includes formatting, Dart and Flutter
analysis, all 25 package suites, analyzer parity, examples and canaries,
preview compilation, Linux integration journeys, Chrome coverage, native
provider fixtures, release/stable audits, generated catalogs, public API and
topology checks, and Android/iOS/Linux/macOS/Windows/Web builds on their
supported hosted runners.

`CI / Required` is the only protected aggregate status. It may succeed only
after every deterministic dependency has succeeded for the merge candidate.
On `main`, the aggregate also creates `actions-readiness-v1` bound to the exact
SHA, tree, run, attempt, job conclusions, native evidence, and repository
artifacts. Security and the resulting `main` aggregate are confirmed separately.

== Explicitly excluded

This candidate does not create or push `v1.1.0-rc.3`, run the `Release`
workflow, create a GitHub Release, publish packages, modify the immutable
`1.0.0` stable release, or promote RC3 to stable. A passing gate does not grant
that authority.
