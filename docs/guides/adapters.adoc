= Optional adapters

== Dio

`DioOwner.create` owns and closes the real client; `.value` borrows it. Header
callbacks run per request and telemetry deliberately omits headers, bodies,
query strings, and user info. `captureDioException` maps only DioException;
programming errors continue to throw. A CancelToken is cooperative, not proof
that an already-running transport operation was preempted.

`DioInstrumentation` records method/protocol/status only and propagates W3C
headers only when a propagator is supplied. It refuses duplicate Dartitect or
`sentry_dio` instrumentation.

== ObjectBox

The consumer supplies its generated `openStore` callback. Dartitect defines no
entity, migration, transaction abstraction, or repository. Register every
subscription, timer, watcher, and query with `ObjectBoxObservationOwner`; the
Store owner drains that registry before Store.close. Temporary-store cleanup
deletes only a directory created and validated by that invocation.

ObjectBox has no web support in this SDK. Use conditional imports or separate
targets; do not disguise a different database as an ObjectBox web fallback.

== Sentry

The consumer initializes and owns Sentry. Inject its Hub into
`SentryLogSink`, `SentryErrorReporter`, and `SentryTracer`; Dartitect never
sets DSN, environment, user, sampling, or closes that Hub.
