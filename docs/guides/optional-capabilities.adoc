= Optional capability contracts

The four capability packages are independent opt-in leaves. Foundation,
runtime, observability, and tooling do not depend on them.

== Permission and native contracts

Construction, composition, and status reads are prompt-free. Only an explicit
consumer interaction calls +request()+ or +requestAccess()+. Unknown native
status is rejected with stable +invalid_status+ and no retained native payload.

[cols="2,3,4",options="header"]
|===
| Media host | Authorization | Save

| Android API 24--28
| Legacy write permission is declared/requested; the plugin-owned history bit
  distinguishes initial +notDetermined+ from +denied+.
| Copies one readable image into MediaStore, removes partial insertion on
  failure, and completes on the main thread.

| Android API 29+
| Legacy write permission is neither declared nor requested; MediaStore
  insertion status is +authorized+.
| Uses scoped MediaStore pending publication and leaves the source untouched.

| iOS 14+
| Photos +.readWrite+ is frozen because optional album lookup/creation requires
  library access; +.limited+ is preserved.
| Requires +.authorized+; limited is a typed failure; the Photos transaction
  creates one asset/optional album association and completes on the main thread.

| Other/web
| +notSupported+ without channel calls.
| +GalleryNativeFailure('not_supported')+ without channel calls.
|===

+saveImage+ reads status but never requests permission. Native failures are
mapped to payload-free stable types. +clearOwnedState()+ removes only the
Android +legacy_write_requested+ preference and is used for package removal,
not routine disposal. +cleanup_failed+ blocks removal and must be retried; zero
residue cannot be claimed after that error.

== Pure-Dart contracts

+BrazilianPostalCode+ accepts eight ASCII digits or the two documented masks,
trims outer whitespace, and makes no existence, assignment, or delivery claim.

Geometry uses finite planar input units. Polygon construction copies and
freezes rings and rejects invalid topology. +defaultGeometryTolerance+ is the
public absolute +1e-12+ bound. Precision is finite, positive, expressed in input
units, and bounds remaining improvement. Equal inputs are deterministic.

Native floor/current builds and real-device lifecycle/permission validation
remain the separate V1S-13 hardening gate.
